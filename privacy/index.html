2. Instagram連携について

当方は、ご契約いただいた事業者様のご依頼により、その事業者様のInstagramの投稿をホームページに表示する機能を提供しています。この機能は、事業者様ご本人がInstagramの画面で「許可」の操作を行った場合にのみ動作します。

取得する情報

  • 投稿の画像・動画のサムネイル
  • 投稿の本文（キャプション）
  • 投稿日時
  • 投稿へのリンク（パーマリンク）
  • Instagramが発行するアクセストークン（投稿を読み取るための鍵）

取得しない情報

当方が求める権限は「投稿の読み取り」のみです。以下は技術的にアクセスできません。

  • Instagramのログイン情報（パスワード）
  • ダイレクトメッセージの内容
  • フォロワーの一覧や個人情報
  • インサイト（分析）データ

また、当方が投稿を作成・編集・削除することもできません。

利用目的

取得した投稿情報は、その事業者様のホームページに表示する目的のみに利用します。他の目的には使用せず、第三者に提供・販売することはありません。

保存と削除

  • 投稿情報は、表示を速くするため最新の一定件数のみを一時的に保存します。新しい投稿を取得するたびに上書きされます。
  • アクセストークンは、Cloudflare社のサーバー上に暗号化して保存します。
  • 事業者様がInstagram側で連携を解除された場合、または当方との契約が終了した場合、アクセストークンおよび保存していた投稿情報を速やかに削除します。
  • 削除のご依頼は info@tproject-jp.com までご連絡ください。ご本人であることを確認のうえ対応いたします。

連携の解除方法

事業者様はいつでも連携を解除できます。Instagramアプリの「設定とアクティビティ」→「ウェブサイトの許可」から当方のアプリを削除してください。解除してもInstagramの投稿・フォロワーには一切影響しません。

3. YouTube翻訳Bot（papasan翻訳Bot）について / YouTube Translation Bot

当方は、ライブ配信の話し声を英語に翻訳してYouTubeのライブチャットに投稿するツール「papasan翻訳Bot」（以下「本ツール」）を運用しています。本ツールは YouTube API サービスを使用しています。本ツールを利用する配信者は、YouTube 利用規約に同意したものとみなされます。YouTube（Google）によるデータの取り扱いについては、Google プライバシー ポリシーをご確認ください。本ツールの詳細は紹介ページ、利用条件は利用規約をご覧ください。

取得・利用する情報

  • 配信チャンネルの「いま配信中の放送」の情報（放送のID・ライブチャットのID）…どの配信に翻訳を投稿するかを知るため。配信者ご本人が「閲覧のみ」の許可をした場合に限ります。
  • 翻訳Botのチャンネル情報（チャンネル名・チャンネルID）…投稿するアカウントを確認するため。
  • 配信の音声…配信者の話し声を文字にして翻訳するため。音声は当方のパソコンの中で文字にし、音声そのものは保存しません。
  • 文字にした話し声と、その英訳…ライブチャットへの投稿と、配信者本人が配信後に字幕を作るため。英訳のために文字にした話し声を Google 翻訳に送ります。
  • Google が発行するアクセストークン（許可の鍵）…上記の操作を行うため。

取得しない情報

  • Googleアカウントのパスワード
  • 視聴者の個人情報、視聴者のチャットの内容（本ツールはチャットを読み取りません）
  • チャンネル登録者・再生回数・収益などの分析データ

また、本ツールが動画の投稿・編集・削除、チャンネル設定の変更を行うことはありません。

利用目的と共有

取得した情報は、配信中に話し声の英訳をライブチャットに投稿すること、および配信者ご本人の字幕作成のためにのみ利用します。広告、分析、他の目的には使用せず、第三者に販売・提供することはありません（英訳のための Google 翻訳への送信を除く）。

保存と削除

  • アクセストークンは、当方が管理するパソコン内に保存し、インターネット上に公開しません。
  • 文字にした話し声と英訳の記録は、当方のパソコン内に保存し、配信者ご本人の字幕作成にのみ使用します。保存から30日以内に削除します（配信者ご本人が字幕として書き出したものを除く）。
  • YouTube から取得した放送の情報は、配信中の投稿のためだけに一時的に使い、保存しません。
  • 削除のご依頼は info@tproject-jp.com までご連絡ください。ご本人であることを確認のうえ、7日以内に削除します。

許可の取り消し方法

配信者はいつでも本ツールへの許可を取り消せます。Google アカウントのセキュリティ設定（サードパーティのアクセス）から「papasan翻訳Bot」を削除してください。取り消すと、本ツールは直ちにその配信チャンネルにアクセスできなくなります。

English summary

Tproject operates "papasan翻訳Bot" (the "Tool"), which transcribes a live streamer's own spoken Japanese and posts English translations to the stream's YouTube live chat. The Tool uses YouTube API Services. By using the Tool, streamers agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

  • Data accessed: the active live broadcast ID and live chat ID of the streamer's channel (read-only permission granted by the streamer), the bot channel's name and ID, OAuth access tokens, and the stream audio.
  • How it is used: the stream audio is transcribed locally on our computer and is not stored. The transcribed text is sent to Google Translate to produce English, which is posted to the live chat. Transcripts are kept only so the streamer can create subtitles after the stream.
  • Not accessed: passwords, viewers' personal information, viewers' chat messages (the Tool does not read chat), analytics or revenue data. The Tool never uploads, edits or deletes videos.
  • Sharing: we do not sell or share data with third parties, except sending transcribed text to Google Translate for translation.
  • Storage and deletion: tokens and transcripts are stored only on our own computer and are not published. Transcripts are deleted within 30 days. Broadcast data from YouTube is used only during the stream and is not stored. Deletion requests: info@tproject-jp.com (handled within 7 days).
  • Revoking access: streamers can revoke the Tool's access at any time via Google Account security settings.

4. アクセス解析について

当方が制作・運用するホームページには、Googleが提供するアクセス解析ツール「Googleアナリティクス（GA4）」を設置する場合があります。

取得するもの：閲覧されたページ、閲覧数、おおまかな地域、使用された端末の種類、参照元、ボタンのクリック数（LINE・Instagramへのリンクなど）。

取得しないもの：閲覧された方のお名前、ご住所、電話番号、メールアドレス。当方がこれらを知ることはできません。

これらはCookieおよび類似の技術によって収集され、個人を特定しない形で集計されます。取得したデータは、ホームページの改善および事業者様へのご報告のみに使用します。

Cookieの利用を望まれない場合は、ご利用のブラウザの設定で無効にすることができます。Googleによるデータの取り扱いについては、Googleのプライバシーポリシーをご確認ください。
