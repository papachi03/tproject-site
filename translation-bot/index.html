できること

日本語で話しながら観光地や釣り場を案内するライブ配信で、配信者の話した内容が英語でライブチャットに流れます。英語が話せなくても、海外の視聴者に「いま何を話しているか」が伝わります。

🎙 竿っていう言葉を。
[EN] It's called a rod.
🎙 これで日本語と英語の壁みたいなやつはなくなるはず。
[EN] This should eliminate the barrier between Japanese and English.

配信のあとには、翻訳の記録から英語・日本語の字幕ファイルを作れるので、ダイジェスト動画の字幕にも使えます。

しくみ

  1. 配信者がいつもどおりスマホからライブ配信します。
  2. 本ツールが、配信チャンネルの「いま配信中の放送」を YouTube API で確認します（配信者が「閲覧のみ」を許可した場合）。
  3. 配信の話し声を当方のパソコンの中で文字にし、英語に翻訳します（音声は保存しません）。
  4. 翻訳Botのアカウントが、英訳をライブチャットに投稿します（YouTube API）。

本ツールは視聴者のチャットを読み取りません。YouTube には、チャットを見る人の言語に自動翻訳する機能があるためです。また、動画の投稿・編集・削除や、チャンネル設定の変更は一切行いません。

ご利用にあたって

  • 本ツールを利用する配信者は、YouTube 利用規約に同意したものとみなされます。
  • 取得する情報と保存・削除の方法：プライバシーポリシー（Google プライバシー ポリシーもあわせてご確認ください）
  • 利用条件：利用規約
  • 許可はいつでも Google アカウントのセキュリティ設定から取り消せます。

About papasan翻訳Bot (English)

papasan翻訳Bot helps Japanese streamers reach international viewers. While the streamer talks in Japanese — guiding viewers around tourist spots or fishing grounds — the Tool transcribes the streamer's own voice, translates it into English and posts it to the stream's YouTube live chat.

  • It checks the streamer's active live broadcast with the YouTube Data API (read-only permission granted by the streamer).
  • Audio is transcribed locally and never stored. The text is translated into English.
  • The English text is posted to the live chat by a dedicated bot account via the YouTube Data API.
  • The Tool does not read viewers' chat messages and never uploads, edits or deletes videos.
